# micro-short-drama-ai
Micro Short Drama AI adalah knowledge base dan kerangka kerja (framework) penulisan cerita terstruktur untuk produksi short drama vertikal maupun AI video storytelling. Seluruh pola di dalamnya telah divalidasi dari 300+ AI short drama terpopuler dan dirumuskan secara netral agar fleksibel diadaptasi ke berbagai latar zaman maupun genre murni.
